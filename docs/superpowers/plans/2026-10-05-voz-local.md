# Voz local (Fase 1): plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Trocar a Web Speech API por um serviço local de voz (Pipecat + Whisper MLX + Silero + smart-turn + ElevenLabs WS) que fala com o cérebro na Vercel, sem cortar o Rodrigo nem errar o vocabulário dele.

**Architecture:** Serviço Python em `voice/` (uma sessão Pipecat por conexão WebRTC) com um gate de conversa que reproduz o UX de wake word e follow-up. O cérebro ganha o modo `stream: "ndjson"` e aceita um token de serviço. O navegador ganha `VoiceLink`, usa o serviço quando ele responde em `/health` e cai na Web Speech quando não.

**Tech Stack:** Python 3.12 + uv, pipecat-ai 1.12 (`[silero,local-smart-turn-v3,mlx-whisper,whisper,elevenlabs,webrtc,runner]`), httpx, pytest; Next.js 14, `@pipecat-ai/client-js` 1.13, `@pipecat-ai/small-webrtc-transport` 1.10, `node --test`.

**Spec:** `docs/superpowers/specs/2026-10-05-voz-local-design.md`

## Global Constraints

- Todo parâmetro (tempos, vocabulário, modelo, limites) vem de `voice/beto-voice.toml` ou env; nenhum fixo no código.
- Sem rede nem modelo nos testes: `pytest` roda em segundos; `npm test` idem.
- O caminho Web Speech atual continua funcionando quando o serviço não está no ar.
- Nenhum segredo no repositório; `voice/.env` está no `.gitignore` (`.env*` já cobre).
- Mensagens ao usuário, comentários e commits em português, no estilo do repositório (`feat:`, `fix:`, `docs:`).

## Review Focus

1. Transcrição com wake word e nada mais ("Beto.") abre o gate e NÃO chama o cérebro (teste em Task 3).
2. Linha NDJSON malformada ou stream cortado no meio: o serviço fala o que chegou e não trava (Task 5).
3. Tag de ação chegando partida entre dois pedaços (`[SPOT` + `IFY:{…}]`) é detectada inteira (Task 2).
4. `undo` do My Hub sobrevive entre turnos e some após `undoCleared` (Task 5).
5. Token de serviço só vale em `/api/chat` e só com a env definida (Task 7).
